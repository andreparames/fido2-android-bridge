## Scenario

Your developers live on SSH bastions and client infrastructure. Client admin panels, CI dashboards, and control-plane interfaces increasingly ask for security-key sign-in. You care about security, but a YubiKey for every developer on every client engagement does not pencil out.

## How Gatebridge helps

- One phone per developer covers every client server they touch.
- Per-team access lists scope credentials to specific apps and servers.
- The audit log answers "who signed in to which client's panel, when, from where."
- Lost-phone recovery without a support ticket or key reissue.

## Typical setup

```
Developer laptop → Client SSH bastion → Client admin panel → Developer's phone
```

## What it costs

The Team plan (about $5 to $10 per person per month) includes the admin console, audit log, recovery, and bulk onboarding. Move to the Business tier when you need single sign-on and a support agreement.
